# Arrow Functions & Ternary Operator – Assignment

This repository contains JavaScript solutions demonstrating:

- Arrow Functions  
- Ternary Operator  
- Simple Conditional Logic  
- Default name handling using ternary  

---

## 📁 Files Included
- `index.js` → Contains answers for all assignment questions  
- `README.md` → Project explanation  

---

## 📝 Assignment Tasks

### **a) isEven(n) – Arrow Function**
A function that returns `true` if the number is even, otherwise `false`.

### **b) Ternary Operator Conversion**
Rewritten the classic `if–else` logic to decide `"Pass"` or `"Fail"` using a ternary operator.

### **c) greet(name) – Arrow + Ternary**
Prints `"Hello, <name>"`.  
If no name is passed → prints `"Hello, Guest"` using a ternary operator.
